# 声音：温暖白天、安静夜晚、自然脚步

用于默认温馨游戏及用户明确要求的昼夜声音设计；其他风格按用户要求调整。音量数值是调音结果，不把某次修复的固定系数推广到所有游戏。

## 昼夜混音

- 早晨/白天采用温馨、轻柔、循环自然的 BGM，脚步置于背景音乐之下但仍可辨认。音乐不能用来掩盖刺耳、削波或错误的脚步素材。
- 夜间关闭日常探索 BGM，保留较轻的虫鸣和稀疏、随机间隔的猫头鹰声。夜间脚步可以相对环境更明显，同时保持柔和、低冲击；用户说“再柔和些”时先调整脚步自身，不提高夜间环境声来遮盖它。
- 用平滑包络切换昼夜与区域，不突然重启曲目、截断音频或叠加重复播放器。特殊事件/战斗音乐按项目已定规则处理，不擅自覆盖明确的“夜间无音乐”要求。
- 主音量、音乐、音效、环境声分总线组织，UI 暴露的滑块应覆盖对应总线并保存；环境可有独立滑块，也可受明确的音效总线控制。时间系数叠乘用户设置，不能重置用户音量。

## 脚步与素材

优先使用合法自然的落脚素材，或经过实际听感验收的原创合成素材。短白噪声脉冲不因“能发声”就成为可交付脚步。

按落脚事件或实际移动距离触发，保持与动画接触一致；地表可区分石、土、草、浅水。少量不同采样和轻微音高/音量变化减少机械重复，不破坏角色体重感。控制多音重叠，避免同帧多次触发。

停步、碰墙、打开阻断移动的菜单、对话、切场景时不继续触发脚步；已有尾音可短淡出。原地转向不生成不合理步声。传送、读档和时间跳转重置节拍状态，不补播累计事件。

柔化优先检查素材的尖锐起音、高频、低频重击与削波，再调整包络、滤波、音量和变化幅度。循环音乐/虫鸣检查接缝，猫头鹰避免固定短周期与连续叠叫。

## 验收

分别试听白天静止/移动、夜晚静止/移动、昼夜过渡、室内外和不同地表；检查常用音量及低音量下的疲劳感、可辨性和突然惊跳。实测峰值、RMS 或响度辅助排查，但数字不能证明温馨或柔和。

验证音乐静音、音效静音、主音量、暂停/恢复、保存重启后的设置与混音。无法实际试听时提供可播放的对比片段并标明仅做了哪些测量；不能写“已听过、很自然”。
