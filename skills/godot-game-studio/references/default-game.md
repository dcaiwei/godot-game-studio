# 默认方案：中文 HD-2D 精灵捕捉 RPG

仅在用户没有指定不同产品方向时采用。这里保留原始提示词的设计契约；现有项目以已确定的范围为准。原提示词中的“未来支持”与首版可玩内容必须分开记录，数据结构存在不等于功能完成。

## 气质与首版

原创、温馨、可爱、魔法中世纪；像素或像素感角色置于有空间层次的精细 3D 环境中。角色设计漂亮、身份鲜明，精灵轮廓易辨、有生态特征和收藏价值。女性角色的魅力来自设计、表情和性格。避免通用低多边形演示、原始几何体怪物、高清立绘直接缩小充当游戏角色。

默认首版包含一个精致村庄、一片草原或森林、一处水域、一处雪地/洞穴/遗迹等特色区域，6–12 种有实际差异的原创精灵，以及少量有性格的 NPC。区域可以连成紧凑世界，不用空旷面积冒充内容。先完成一个区域的完整闭环，再扩展到已选定的首版范围。

## 捕捉与个体外观契约

- 地图中观察目标、选择工具、瞄准、投掷；真实投射物可能扔歪、撞墙或落地。合法命中才进入捕捉判定。轨迹、消耗、命中、失败和成功都有一致反馈，不以菜单按钮代替地图捕捉。
- 普通捕捉率读取物种难度、血量/状态、球与环境等已实现因素；向玩家提供足够提示，不堆不可理解的隐藏系数。低价球拥有情境价值。
- 天然异色 `natural_variant_id` 只改变该物种指定区域；捕捉印记 `capture_imprint_id` 只改变另外的指定区域，默认不重叠；`vfx_modifier_id` 独立。合成顺序为基础外观、天然异色、印记、特效、环境光照，不允许全图改色抹掉设计。
- **拥有永久印记功能的球，真实命中合法可捕捉野生精灵时，捕获成功率为 100%。** 它仍可能物理投失；不可捕捉目标不绕过限制。这类球必须稀有且获取成本与经济节奏匹配。
- 每只个体拥有稳定唯一 ID，保存物种、等级、经验、个体成长数据、天然异色、捕捉球、印记、特效及已实现的特性/性格。界面、世界、战斗和读档后外观一致。
- 球、诱饵、食物、镇静或束缚工具按明确首版范围实现；未来工具留合理扩展点，不做空按钮充数。

## 世界与生态

区域、时间、天气影响生态，玩家能观察并理解其规律。天气配置架构支持晴、阴、小雨、大雨、雷雨、雾、雪、暴雪、沙尘与魔法天气；只在适合的区域启用，不把所有天气强加给所有地图。配置表存在不代表对应视觉和玩法已实现。

天气影响光照、雾、能见度、地表/水体、植被、粒子和环境声。草经过时弯曲再恢复；浅水有足步波纹/水花；雪有积雪世界与可行的脚印反馈。未实现项明确记录。

默认采用稳定回合制：技能、生命、伤害、速度与回合顺序、属性、状态、胜负、经验和升级。队伍更换、技能成长和探索解锁形成持续目标；详见玩法规范。天气或道具作弊入口与正式游戏分开，不能让免费随时切天气消解稀有生态价值。

## 中文与界面

玩家正常接触的标题、菜单、地名、NPC 对话、图鉴、物品、技能、天气、教学、战斗、保存提示均为自然简体中文。代码 ID 可英文。字体授权明确且覆盖中文，检查长文本、缺字、缩放与输入焦点。

标题含开始、继续、设置、退出；新游戏不能无提示覆盖已有进度。暂停含继续、队伍、图鉴、背包、地图、设置、返回标题。设置含主音量、音乐、音效与窗口/全屏，分辨率和画质按平台合理提供。无存档的“继续”状态应清楚。

HUD 清楚呈现当前工具及数量、队伍/生命、互动与捕捉反馈；战斗指令明确。使用统一的魔法中世纪视觉语言，避免默认灰色控件和满屏调试数据。
